🔧 Developer API

Want to integrate this AI power into your own applications? Use these API endpoints:

Single Text Analysis:
POST /api/analyze
{"text": "your text here"}
Batch Analysis:
POST /api/batch
{"texts": ["text1", "text2", "text3"]}
Model Information:
GET /model-info

Note: This demo uses a local AI model. For production use, consider hosting the Flask application on a cloud service like Heroku, Railway, or DigitalOcean.
